This is a simple server-side plugin I'm working on with my son. Move the file 'original-CustomFoods-1.0.0.jar' to your plug-ins folder. 
Find your server.properties file. Edit the file. Identify the fields of require-resource-pack= and resource-pack=
Edit each to match below:

require-resource-pack=true
resource-pack=https\://github.com/kd2270/CustomFoods/blob/main/CustomFoods_ResourcePack.zip

Restart your server.
